# @deepseek-ai/dsh-client-ui-agent-mesh

[English](README.md) | 中文

## 概述

「智能体」页面列出外部智能体、它们的原生会话与转录、本地任务、凭据、已派发运行、会话绑定和可复制的原生续接命令。任务表单可将工作排入当前打开的 Harness 会话，由模型通过 `mesh_run` 和 DSH 常规审批流程派发。「协作」页签显示共享计划、任务、待办板、工作树进度和建议性冲突报告；用户可将工作树状态标记为已合并。`/` 菜单提供当前会话所绑定智能体的技能与文件型命令。智能体运行仍须通过 DSH 审批。

<a id="use-this-package"></a>
## 使用本包

通过 web-app 清单加载本插件。「智能体网格」入口打开的是一个全局页面：它属于 profile 而不属于某个会话，因此任何对话打开时它都可用。刷新会重新读取页面正在展示的全部内容，连接重置也会如此。

Harness 会话绑定到某个智能体后，`/` 菜单会按该会话的工作目录读取并列出其本地技能与文件型命令。选择技能会插入委派提示；选择命令会插入一段可编辑提示，写明准确的 agent id 与 `mesh_run.commandName`。用户通过普通 composer 提交后，模型仍须通过 DSH 审批才能派发运行。

第一列列出每个已注册的智能体，包括是否已安装、二进制报告的版本、解析出的可执行文件路径、探测失败时的原因，以及适配器给出的警告。选中某个智能体会列出该智能体自己的会话（最新的在前），每条包含记录的标题、工作目录、模型、最后更新时间、上报状态、消息数，以及适配器的说明。会话行沿用源存储的 agent id 与 native session id，不会创建 Harness Session。Workspace 浏览器也会将这些行与 Harness 会话并列显示；选择其中一行会在此处打开对应会话。

选中某个会话会同时读取它的转录与本地任务。转录按智能体记录的顺序渲染每条消息：角色、工具调用或结果的工具名、失败与截断标记、记录的时间戳，以及消息正文或工具的输入输出。适配器只能投影为通用类别的记录会显示其本地记录类型，而不是虚构的类别。任务区先显示智能体自己的待办及其状态与阻塞键，再显示其计划，步骤顺序沿用智能体自己的顺序；不记录本地任务模型的智能体会直接说明，而不是显示空列表。

会话详情可以请求 adapter 生成原生 TUI argv，并将 shell 转义后的命令与复制按钮一起展示。页面不会启动可执行文件；只有用户把命令粘贴到 DSH Host 的终端中才会运行。未提供此能力的 adapter 会明确显示不可用。

会话详情也可以为选中的原生会话填写任务。提交后，页面会把带有准确 agent id、工作目录、原生会话 id 和任务正文的用户消息排入当前打开的 Harness 会话。模型按常规 DSH 审批流程调用 `mesh_run`；页面不会直接启动外部智能体。此操作要求当前有打开的 Harness 会话，且原生会话记录了工作目录。

会话绑定区显示当前打开会话绑定的智能体。从列表中选择一个智能体即把该会话绑定到它，解除绑定则移除该绑定；两者都会回读绑定并把失败就地报告，而没有绑定的会话与没有打开会话的页面各自说明自己的状态。

账号区列出每个智能体的凭据状态、观察到该状态的来源、凭据类型，以及适配器报告的任何详情或过期时间。「登录」菜单只列出该适配器声明的流程；仅当适配器能移除当前来源的凭据时才显示退出登录按钮。CLI 无法移除环境变量提供的凭据。API 密钥流程会显示密码输入框；提交后，密钥只随本次登录请求发送，且会在请求结束前从输入框清除。Codex 会通过 stdin 接收密钥，Client 不会保存或记录它。适配器无法自行完成的登录会返回用户需要执行的说明，页面会展示这段文字。

运行区列出网格跟踪的运行，包含运行 id、智能体、运行自身状态、上报的回答或带错误码与处理建议的分类失败，以及适配器的说明。空闲列表每 5 秒刷新一次；存在活动运行时，每 1.5 秒刷新记录。进行中的运行提供「取消」。每行可展开查看最近 20 个事件；预览不显示推理文本、工具输入或工具输出。取消失败会在列表旁报告，并且不会隐藏上次已知的运行行。

选择「协作」即可查看每项协作的共享计划、已派发任务、共享待办、工作树进度和建议性冲突分析。页面通过原生 `meshCollaboration` Remote 命名空间读取这些记录；有任何任务正在运行时，每 3 秒刷新一次，否则每 15 秒刷新一次。页面也可以将工作树状态标记为已合并；该操作只记录状态，不会合并 Git 分支。冲突分析不会阻止任务派发。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

浏览器入口注册 `agents` 主面板、对应的 `sidebar.panellist` 行，以及 `ctx.inputTriggers` 上的 `/` source。该 source 先解析当前会话的绑定与工作目录，再读取智能体本地技能与命令清单；它只提供文件型命令，因为 `mesh_run.commandName` 无法派发没有提示文件的代码型命令。选择后只会插入普通草稿文本；客户端不会读取外部提示文件，也不会启动运行。该页面不声明任何子插槽、不发布对话节点，也不拥有工具视图：模型 `mesh_*` 工具背后的同一个 Host 网格服务同时回答它的 Remote 读取，因此某个能力会同时出现在两个界面上，或都不出现。

apply 闭包中创建的一个 `mesh` 数据源持有页面渲染的全部事实——智能体名册、某个智能体的会话、某个会话的转录与本地任务、凭据行、绑定与运行——以及当前选中项，并暴露组件调用的读取与变更动作。渲染器把它的快照绑定到页面的 `useMesh` 选择器 Hook，因此组件自身不订阅任何东西。该数据源只在有订阅者时安装连接重置监听、在第一个订阅者到来时读取各列表，并在最后一个订阅者离开时清空状态与在途应答，因此重新挂载会重新读取事实，而不会展示上一代的结果。

每次读取都带有一个以其寻址对象为键的纪元（名册、某个智能体的会话、某个会话的转录或任务、凭据、绑定、运行）。同一键上只有最新的请求可以发布结果，因此用户已经离开的会话的迟到应答不会替换当前内容。调用失败时保留已经显示的行，并报告 Remote 失败的消息——那是页面从线路上逐字复述的唯一文本。

选中项存放在数据源而非组件状态中，因此连接重置后的回读会重新读取屏幕上正在展示的内容：所选智能体的会话列表，以及每个已请求会话的转录与任务。

协作页面使用独立的 Remote 数据源，并按协作和代码库索引。每项协作保留其计划与任务列表；页面读取所选待办板和代码库工作树，仅在用户请求或已有报告需要刷新时才计算冲突。周期性读取与连接重置监听共享订阅生命周期：页面有订阅者时开始轮询，最后一个订阅者离开时清除定时器、阻止在途结果发布，并在当前 Remote 调用完成后停止刷新链；按键纪元会阻止过期响应覆盖新状态。标记工作树已合并会通过协作 Remote 更新其状态。

<a id="model-experience"></a>
## 模型体验

无，本浏览器面板只呈现模型工具已能访问的 mesh 服务，不注册 prompt、工具 schema 或 Session 事件。

#### KV Cache effect

面板不会添加模型上下文；提交的任务通过 Session 消息进入，不会改变可复用的 system prefix。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

这些限制说明本包当前的约束，而不是待办清单。

- **派发使用当前 Harness 会话** ——任务表单要求该会话已打开且原生会话有工作目录，然后把消息排入 DSH 会话供模型在 DSH 审批后调用 `mesh_run`。页面不会直接启动外部智能体，也不创建协作、不编辑计划或待办板、不合并 Git 分支。「智能体」页签可以取消已跟踪的运行，「协作」页签可以将工作树状态记录为已合并。
- **运行更新使用轮询** —— 数据源存在订阅者时，页面每 5 秒刷新空闲运行列表；存在活动运行时则每 1.5 秒刷新。页面最多显示注册表保留的最近 20 个事件，卸载面板后会暂停轮询。
- **绑定依托当前会话** —— 绑定区读取由主视图保留的会话。没有打开会话时，或另一个主面板在没有会话的情况下显示时，它会说明该状态，而不是提供绑定。
- **凭据流程遵循适配器声明** —— 页面只列出适配器声明的登录流程，并且只在适配器能移除当前来源的凭据时提供退出登录。CLI 无法移除环境变量提供的凭据。API 密钥通过密码输入框提交一次；需要人工参与的交互流程则会返回操作说明。
- **适配器决定转录携带什么** —— 被适配器丢弃或投影为通用类别的记录，到达这里时就是该投影，或者根本不出现；页面复述适配器的说明，而不会自行读取某个智能体的存储。Workspace 浏览使用相同的源会话身份，在此处打开选中的记录。
- **菜单不会载入本地指令** —— 选择技能会写明其智能体与技能名称，选择文件型命令会写明准确的 `mesh_run.commandName`；两种选择都不会读取外部指令文件或启动运行。模型可通过 `mesh_capability_read` 读取已声明文件，派发的命令则会在常规 DSH 审批后通过 `ctx.fs` 读取模板。
